# V5.8 实施与验收计划

1. 固定 V5.7.1 基线并记录范围（已完成）。
2. 第一纵向切片：HTTP 提交反馈，服务器捕获原成果快照，读取与幂等验证。
3. 第二纵向切片：人工接受/驳回、版本冲突与并发、样例原子生成和用途隔离。
4. 第三纵向切片：确定性导出、来源模式隔离、数据迁移回环。
5. 第四纵向切片：成果反馈表单、评测中心审阅页、真实错误与重试；客户接口与浏览器测试。
6. 固定基线差异双轴独立审查，每项发现复现并修复；保留审查结论。
7. 全后端、前端单元/lint/typecheck/build、固定 60 场景、两次独立 Strict E2E；缺依赖不得算作通过。
8. 更新版本与验收证据，追加学习/交付日志，发布包校验，独立分支推送。完成本阶段即停止，不扩展成自动学习或公网服务。

测试接口：/api/v1/feedback 及其 review、cases/export；前端 FeedbackClient；成果页到审阅页完整流程。服务内部私有方法不是断言目标。数据库只用于准备真实隔离测试数据和迁移验证。
