# Learning Loop

## Implemented Loop

```text
Project source
-> source chunk or multimodal chunk
-> RAG answer or learning artifact
-> knowledge point
-> card / quiz / note / interview expression
-> version learning archive
```

## Implemented Learning Artifacts

- Knowledge points.
- Learning cards.
- Quiz questions.
- Notes.
- Interview expressions.
- Version learning packages and logs.

## Archive Rule

`docs/learning_log.md` and `docs/stage_delivery_log.md` are append-only. New delivery records must be appended, never rewritten.
