# V4.7 Visual UX Report

V4.7 reduces page clutter by prioritizing visual workflow regions over long text blocks.

## Dashboard

- Added a `dashboard-hero` action area.
- Added capability bars for real system readiness.
- Added task distribution based on real ingestion jobs.
- Added action tiles for upload, task review, chat, project structure, learning assets and portfolio.
- Kept recent evidence and learning archive visible without turning the page into a card wall.

## Task Center

- Added per-task pending feedback for retry/cancel.
- Kept event timeline and recovery hints as the detail area.

## Learning

- Added pending states for card review, quiz submission and package confirmation.
- Kept deep learning pages available while reducing AppShell entry count.

## Portfolio

- Existing generation/export buttons already had busy states.
- Portfolio remains evidence-oriented and does not claim provider generation when LLM is unconfigured.
