# Demo Storyboard

This storyboard supports a 60-90 second GitHub portfolio walkthrough using synthetic data.

## Scene 1: Dashboard

- Show version, counts and recent learning state.
- Say: "This is a local multimodal knowledge OS for AI application learning."
- Boundary: demo data is synthetic and labelled.

## Scene 2: Upload Center

- Show document, image, audio and video upload lanes.
- Say: "Each source type enters a real processing pipeline, and provider-backed steps refuse when unconfigured."
- Boundary: do not imply demo data came from real providers.

## Scene 3: Task Center

- Show progress, stages, retry/cancel controls and result links.
- Say: "Long-running work is tracked through durable jobs instead of hidden request-time work."

## Scene 4: Media Library

- Show source cards and media metadata.
- Say: "Images, audio and video share source, asset, transcript, frame and chunk concepts."

## Scene 5: Video Detail

- Show player, transcript timeline and keyframes.
- Say: "Video citations can point to timestamps and transcript segments."

## Scene 6: Knowledge Chat

- Ask a project question.
- Show citations.
- Say: "The assistant is useful only when answers remain traceable to evidence."

## Scene 7: Learning Archive

- Show knowledge points, cards, notes and version records.
- Say: "Each version becomes a learning artifact that can feed review and interview preparation."

## Scene 8: System Status

- Show capability matrix.
- Say: "The project is explicit about what is directly usable, what needs services and what needs provider keys."

## Capture Checklist

- Hide absolute private paths when possible.
- Do not show `.env` or provider keys.
- Prefer synthetic demo data.
- Confirm there is no "Failed to fetch" state.
- Confirm screenshots do not overlap or expose raw debug JSON on the main UI.
