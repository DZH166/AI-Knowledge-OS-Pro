# AI Knowledge OS Pro V4.5 Release Notes

## Highlights

- Promoted the seeded browser demo to a strict live E2E gate for prepared environments.
- Added `npm run test:e2e:strict` and `scripts/run_demo_e2e.py --strict`.
- Added a GitHub Actions `live-e2e` job with Playwright Chromium installation and artifact upload.
- Strengthened demo smoke, citation jump and observability browser specs with stable locators.
- Added focused transcript timeline component coverage for audio/video timestamp highlighting.
- Updated V4.5 version, docs, quality gates, release checks and portfolio README evidence.

## Honesty Boundaries

- Optional E2E still reports explicit skip reasons when Playwright or browser binaries are unavailable.
- Strict E2E fails when browser runtime dependencies are missing.
- Provider checks do not call paid APIs in default CI.
- Missing LLM, embedding, OCR, vision and transcription providers remain NOT_CONFIGURED-style states.

## Upgrade Notes

Run frontend dependency installation before strict browser E2E:

```powershell
cd frontend
npm ci
npx playwright install chromium
cd ..
python scripts/run_demo_e2e.py --strict
```

## Release Artifact

The local release zip is generated by:

```powershell
python scripts/release.py --version V4.5
python scripts/check_release.py --version V4.5
```

The `.sha256` sidecar is the source of truth for the final local archive digest.
