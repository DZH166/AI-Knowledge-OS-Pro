# V5.9 三资料对比研究流程：阶段验收

日期：2026-09-26—27。固定基线：`dae1bccd3837b582216e753a7f931ef918658218`；分支：`codex/v5.9-research-journey`。这是现有 V5.8 产品上的一项候选升级，**没有更改产品显示版本，也不宣称已正式发布**。

## 本阶段交付

- 工作台新增三资料对比入口：按当前空间统计已有有效版本的文档，明确显示尚不可用、失败及退役状态；至少选择三份不同文档，并填写比较维度后才可发起。
- 比较目标保留用户问题与维度，要求逐份提供可回原文的证据、资料间冲突和证据缺口；提交固定来源、只读权限、对比报告和现有分步 Agent 模式，保留 4000 字边界。
- 上传页在该流程内锁定原知识空间，只列出该空间的文档；上传成功不等于可引用。模型、向量生成、向量库和队列的准备状态提前说明，实际启动仍由后端把关。
- 录制演示增加第三份明确标记为合成样例的资料。三条示例结论、审批目标、成果标题与三份固定来源版本一致；录制结果反复说明不等于真实模型质量，不保存反馈。
- 真实成果保留已有的结论—证据—原文深链和反馈表单；这轮未改动反馈后端，也没有引入新的模型或自动写入能力。

## 明确未验证

- 本机 `dockerDesktopLinuxEngine` 管道不存在，未运行依赖 Docker 的严格真实服务端到端套件；不能挪用旧版 47/47 成绩。
- 没有配置、调用或购买真实大模型；录制样例的三条结论不是根据用户问题实时生成的，60/60 是固定离线样例，不代表真实业务回答准确率。
- 本轮浏览器的真实模式页面使用受控 API 响应；反馈失败与草稿保留、成功响应与页面确认均经过浏览器复核，但真实反馈成功落库及真实上传完成需要服务启动后再做严格端到端验证。后端现有反馈接口逻辑由全量回归覆盖。
- 发布包、Docker 真实服务、多人权限隔离和公网部署不属于本阶段交付。现阶段不应把本分支当作已发布的生产版本。
