## 浏览器运行与隔离

复现命令：

```text
python scripts/run_demo_e2e.py --strict --run-token audit571-a-20260906 --frontend-port 0 --backend-port 0 --redis-port 0 --qdrant-port 0
python scripts/run_demo_e2e.py --strict --run-token audit571-b-20260906 --frontend-port 0 --backend-port 0 --redis-port 0 --qdrant-port 0
```

每次创建独立 SQLite、Redis、Qdrant 和 3 个 RQ Worker（后台执行进程），前后端只监听本机地址。两次都验证了前后端进程、Worker、容器与临时数据库 sidecar 的定向清理，未触碰正式数据库或其他容器。

新增/加强的浏览器断言包括：后端已提交但响应中断后的创建重试不重复；不手动重载页面即可观察评测完成；3 个 Trial 的完整对比；创建分享后刷新页面再复制、查看、撤销；390px 窄屏与键盘操作。

这些浏览器测试使用 `next dev` 开发服务器与真实后台基础设施，模型结果是明确标注的 demo/录制数据，部分界面/异常契约场景使用定向网络桩。独立 `next build` 验证生产构建；未宣称完成真实模型或生产部署压测。

不要将使用默认 `--basetemp=.pytest_tmp` 的 pytest 与这套运行时并行启动，pytest 会重建它的临时根目录。需要并行时，给 pytest 指定一个独立子目录。
