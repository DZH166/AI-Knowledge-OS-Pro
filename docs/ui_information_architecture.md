# 界面信息架构（当前）

溯知的界面按“研究工作流”组织，而不是按后端模块组织。默认只暴露四个一级入口：

1. **研究工作台**：提出问题、固定证据范围、选择交付物与预算，开始一次可核验研究。
2. **运行记录**：查看进行中、已完成、证据不足或取消的运行，进入 Run Workspace 或轨迹页。
3. **证据资料库**：查看来源、活动版本、索引状态和**存储完整性**；从这里摄取新来源或派生成果。
4. **研究成果**：查看已发布的 claim-level Artifact，并回到固定来源版本。

## 次级入口

`开发者模式` 默认折叠，保留旧版总览、旧版知识库、摄取与上传、多模态来源、传统 RAG 问答、学习资产、作品集工具、系统与观测。它们用于工程诊断和兼容，不占用主流程注意力。

## 页面结构约定

- 每个页面先说明“现在要做什么”，再给一个明确的主操作；危险或不可逆操作必须有确认或可恢复路径。
- 中文优先。状态、空状态、按钮和错误信息使用产品语言；内部字段名只在技术详情里出现。
- 列表与卡片共享同一份筛选、搜索与来源身份；搜索不会悄悄改变已选择的证据范围。
- 存储类信息直接说清“检查了什么、还缺什么、下一步怎么做”，不把“文件存在”当作“内容正确”。
- 移动端导航变成抽屉，网格折叠为单列或两列；不允许横向滚动。

## 历史说明

V2.5 的旧版导航按“学习工作台 / 知识库 / AI 助手 / 学习成长 / 系统”分组。V5 之后核心路径收敛到四个研究入口，旧分组保留在开发者模式中用于兼容与诊断。
