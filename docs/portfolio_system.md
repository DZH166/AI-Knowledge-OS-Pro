# Portfolio System

The portfolio system is planned for V4.0. The current repository has README, resume pitch and learning artifacts, but not a dedicated portfolio UI/API.

## Existing Baseline

- Professional README.
- Demo script and screenshots.
- Resume pitch document.
- Versioned learning logs.
- Learning artifacts with interview expressions.
- Release safety checks.

## Target Pages

- `/portfolio`
- `/portfolio/resume`
- `/portfolio/interview`
- `/portfolio/project-review`

## Target APIs

- `GET /api/portfolio/summary`
- `POST /api/portfolio/generate-resume-entry`
- `POST /api/portfolio/generate-interview-qa`
- `POST /api/portfolio/generate-project-review`
- `POST /api/portfolio/export-markdown`

## Output Types

- Resume version.
- Interview version.
- GitHub README version.
- Project review version.
- Future portfolio website version.

## Current Status

- Dedicated portfolio module: planned.
- Current docs provide a strong starting point but should not be described as a completed in-app portfolio system.
