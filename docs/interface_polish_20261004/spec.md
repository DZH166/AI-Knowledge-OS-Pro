# 界面体验改造 · 2026-10-04

## 目标与边界

用户要求重点改善页面流畅性、可视化和可操作性，减少通用 AI 模板感；上网寻找并拉取优秀开源前端项目。
保留 Next.js 15、React 19、CSS Modules 与原生 CSS。保留当前未提交的 V5.10 可靠性修复，不把它们误记为本轮新功能或已验收发布。
页面实施阶段不修改后端、数据库、真实模型配置、发布版本和运行身份协议，原阶段不推送或合并远程代码。阶段结束后用户明确要求 GitHub 同步，另按该授权保存现有代码与验收记录；没有扩大为主分支合并或正式发布，记录见验收报告。

## 验收要求

1. 拉取官方 shadcn/ui 与 Tremor 的只读源码参考，记录网址、提交与许可证；不执行参考项目脚本，不整体替换技术栈，不将嵌套仓库提交。
2. 四个核心入口统一采用紧凑、低饱和的工作软件布局。减少大标题、重复说明、装饰卡片和过量首屏留白；保留真实与演示的明确标记。
3. 资料选择可直接搜索并查看选择数量；筛选不得改变已经固定的资料范围。提交、恢复、草稿、审批、取消与精确引用行为保持不变。
4. 研究过程增加基于真实公开状态和证据关系的可视化摘要。不同于完成率；不捏造速度、质量分或推理进度。所有提示用中文解释。
5. 资料库提供可切换的紧凑列表/卡片视图、筛选结果数量、无结果时清除筛选入口。搜索输入不被大列表渲染阻塞。
6. 控件有悬停、按下、焦点和加载反馈；支持键盘、窄屏和减少动态效果系统设置。优先 transform/opacity 动画，不引入滚动劫持、背景视频或额外大型组件库。
7. 前端完整单元测试、静态检查、类型检查、生产构建通过；保留原有受控浏览器回归，实际检查桌面与手机页面、选择/搜索、草稿恢复和演示审批链路。
