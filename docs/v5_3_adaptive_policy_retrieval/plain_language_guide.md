# 溯知 V5.3：策略与自适应检索通俗解释

## 一句话理解

V5.2 解决了“Agent 能不能稳定运行、解释和评测”；V5.3 解决的是“Agent 为什么用这套检索办法，以及新办法怎样经过实验后安全上线”。

## 1. Policy（策略）到底是什么

这里的 Policy（策略）不是一段可以执行的 Python，也不是隐藏 Prompt（提示词）。它只是一组有严格范围的数字：

- 事实问题最多取多少候选证据；
- 比较问题最多取多少候选证据；
- 时间问题最多取多少候选证据；
- 低于多少分的证据不要；
- 同一来源最多保留几条；
- 打开证据后向前、向后读几个相邻片段。

HTTP 请求不能加入未知字段、命令、路径、模型密钥或任意代码。

## 2. Versioned Policy（版本化策略）怎么实现

每次修改都会创建新的 Policy Version（策略版本），旧版本不覆盖。每个版本保存：编号、版本号、标签、完整配置、SHA-256 内容指纹、来源版本、状态和时间。

状态只有三种：Draft（草稿）、Active（活动）、Retired（退役）。数据库用唯一约束保证整个系统同时只能有一个活动策略。

## 3. 为什么每个 Run 都要固定策略

新任务创建时读取一次当前活动策略，把策略编号、版本、指纹和完整配置写进 Run。之后即使管理员启用了新策略，旧 Run 仍使用原快照；Continuation（续跑任务）也继承父 Run，而不是读取最新版本。

这叫 Snapshot Pinning（快照固定），目的是让历史结果可以复现。

## 4. Adaptive Retrieval（自适应检索）升级了什么

以前每种 Requirement（子问题）都固定取 10 条候选。现在：

- Factual（事实型）使用 `factual_top_k`；
- Comparative（比较型）使用 `comparative_top_k`；
- Temporal（时间型）使用 `temporal_top_k`。

检索结果再经过 Score Threshold（分数门槛）和 Source Diversity Cap（来源多样性上限），避免低分证据和同一来源重复占满上下文。Neighbor Window（相邻窗口）决定读取证据前后几个片段。

所有决定会写进 ToolCall（工具调用）和 Run Trace（运行轨迹）。

## 5. Counterfactual Simulation（反事实模拟）是什么

反事实模拟读取某个历史 Run 已经保存的检索参数，再计算“如果使用候选策略，Top-K 和相邻窗口会怎样变化”。

它不会重新调用模型、向量检索、证据工具或外部服务，也不会预测新的回答质量。它能说明策略行为变化，不能冒充真实重新运行。

## 6. 为什么策略不能直接启用

Draft 必须先绑定固定 60 场景评测。评测 Worker（后台任务进程）收到策略快照，在临时目录写入固定策略文件，只能运行仓库评测脚本和固定数据集。

报告必须声明同一策略指纹、60 个案例、全部质量门禁通过、外部 Provider（模型服务提供方）调用为 0，才能授权 Activate（启用）。指纹不同、失败报告或伪造报告都会被拒绝。

## 7. CAS 和 Rollback 解决什么

Activate 和 Rollback（回滚）都带 `expected_active_policy_id`。这是 CAS（Compare-And-Swap，比较后更新）：只有数据库当前活动策略仍是用户看到的那个版本，操作才成功。两个请求同时启用不同版本时只能有一个获胜。

回滚只允许回到曾经活动过的退役版本，并写入 Activation Audit（激活审计记录）。

## 8. Policy Lab 页面能做什么

`/policies` 可以：

1. 查看当前活动策略和历史版本；
2. 只用有界数字创建草稿；
3. 查看字段级差异；
4. 选择历史 Run 做反事实模拟；
5. 运行候选策略固定评测；
6. 评测通过后启用；
7. 打开历史版本回滚。

它位于 Developer Mode（开发者模式）下，不增加第五个一级导航。

## 9. 对求职的价值

这一阶段证明的不只是“会调模型”，而是：

- 能把 Agent 决策规则做成不可变、可审计的数据模型；
- 能根据任务类型改变检索行为；
- 能设计无副作用的策略模拟；
- 能用固定评测控制策略上线；
- 能处理并发启用、历史固定、回滚和错误不降级；
- 能把后端一致性、前端产品流程和真实 Redis/RQ/Qdrant/Chromium 验证串起来。

## 10. 诚实边界

- 没有配置真实大模型、Embedding（向量模型）、OCR（图片文字识别）或语音转写服务。
- 固定评测证明架构、策略绑定和回归行为，不代表真实模型回答质量。
- 反事实模拟不生成新证据或新答案。
- 当前仍是单用户本地工作区，不是多租户云平台。
