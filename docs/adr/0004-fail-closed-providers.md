# ADR 0004：真实模式 fail-closed，demo 模式显式降级

## 背景

Provider、Qdrant、Redis 任一不可用时，系统可以“猜一个答案”让演示继续，也可以直接失败。静默降级会让用户误以为结果是真实的。

## 决定

- 真实模式：依赖不可用或模型输出不符合结构时，返回明确错误，不生成假结果。
- Demo 模式：允许使用确定性 recording 和稀疏检索降级，但 UI 明确标记 demo。
- 评测报告把 synthetic / real provider 分开，不混成一个通过率。

## 后果

- 演示可能不如“永远有答案”顺畅，但不会把失败伪装成成功。
- 真实 provider 配置是使用前提；未配置时用户会看到明确错误。
