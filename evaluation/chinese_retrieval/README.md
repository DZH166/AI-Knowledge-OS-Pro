# 中文检索固定题集 v1

这是一套人工编写的合成检索用例，包含 11 份来源、12 个版本片段、24 个问题（20 个有答案、4 个无答案）。它衡量资料片段能否被找到以及版本、空间和来源隔离，不衡量大模型回答质量，也不是实际用户样本的统计准确率。

`v1.json` 的 `expected` 由人工标记为 `来源/版本/片段`，不从检索算法输出生成。用例覆盖无空格中文、词序与标点变化、中英混排、全角字符、重复泛词、当前与固定历史版本，以及无关/越界反例。`repeat` 表示原样重复该段文本，构造可复现的噪音。

评测器通过真实 SQL 索引的 Stage/Activate 公开入口建立隔离的内存证据库；向量候选显式为空，重排器关闭，不调用模型、外部向量库或用户数据。相同问题分别检查 EvidenceIndex（证据索引）和 HybridRetriever（混合检索器）的关键词路径。

```text
python scripts/evaluate_chinese_retrieval.py --strict --output .controlled_browser_logs/chinese-retrieval-v1.json
```

合并前在同一个数据集摘要下记录改动前与改动后的报告：Hit@1/Hit@5（正确原文是否出现在第 1 条/前 5 条）、MRR（第一条正确原文排名的倒数平均值）、无答案反例是否为空，以及空间/来源/版本/引用身份违规数。正例分母为 20，无答案反例另行统计；不能把两次运行、两条检索路径相加后称为更多独立问题。

原有 `evaluation/v5/corpus/` 的 60 项 Agent 合同独立保留。这里的指标只适用于这份小型、可重复的合成题集；语义同义词、单字查询、真实向量召回和真实模型效果需要另外验证。

CI（云端自动检查）会执行同一评测，并把结果保存到 `v5-evaluation-evidence` 工件。`--strict` 只拦截越界、引用身份错误和无答案反例误召回；它不保证所有有答案的问题都命中，正例指标必须单独查看。评测器回归专门保留一个无字面交集的正例，验证漏召回仍计入分母。
