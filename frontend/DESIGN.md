# AI Knowledge OS Pro Interface System

## Product Character

The interface is a focused AI learning workspace, not a marketing site. It should feel precise, calm, evidence-led, and suitable for repeated daily work.

## Visual Language

- Use neutral paper surfaces, a graphite navigation rail, and evergreen for primary actions.
- Blue, amber, and rose are semantic support colors, not decorative gradients.
- Prefer borders and spacing over large shadows. Cards are reserved for real units of information.
- Keep radii between 4px and 8px. Avoid nested cards and oversized display typography.
- Use the system sans stack for reliable Chinese and Latin rendering. Technical identifiers use the mono stack.
- Letter spacing stays at zero. Headings remain upright and compact.

## Layout

- Desktop navigation is a stable 260px rail; content uses a 1280px reading frame.
- Page headers establish task context, then expose one clear primary action.
- Dashboard hierarchy: next action, core counts, system readiness, task state, recent evidence.
- At mobile widths, navigation becomes an off-canvas drawer and all fixed grids collapse to one column.

## Interaction

- Every interactive control has visible hover, focus-visible, active, and disabled states.
- Motion is short and functional. Respect `prefers-reduced-motion`.
- Icon-only controls require an accessible label and tooltip.
- Real provider and runtime states remain explicit; visual polish must never imply unavailable AI capability.

## Reference

The system applies principles studied from Hallmark (MIT): locked tokens, honest copy, structural hierarchy, restrained surfaces, responsive safety, and anti-template visual review. No Hallmark page or brand asset is copied.
